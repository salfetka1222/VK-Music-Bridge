# VK Music Bridge

Telegram bot project for organizing music links from VK in a private Telegram chat.

## Status

Initial project setup. Implementation has not been added yet.

## Planned direction

- Telegram bot interface for submitting VK music links.
- Use official, permitted access methods and respect VK and Telegram platform rules.
- Only handle audio the user is authorized to access and share; do not bypass access controls or redistribute copyrighted tracks without permission.
- Keep API tokens and other secrets in environment variables; never commit them to the repository.
